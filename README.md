# Quant Finance Roadmap

Учебный roadmap для входа в quantitative finance, алгоритмическую торговлю и применение Python/ML к финансовым данным.

Проект сделан как практический учебник: не просто список тем, а последовательность того, что стоит изучать, в каком порядке и зачем.

## О проекте

Этот репозиторий — попытка структурировать путь начинающего в quant finance:

- что нужно уметь писать руками в коде;
- какие финансовые и статистические концепции нужно понимать;
- какие инструменты стоит осваивать постепенно;
- как связать теорию с практическими проектами.

Главная идея: часть навыков лучше учить через код и эксперименты, а часть — через чтение, понимание и объяснение своими словами.

## Для кого

Материал подойдёт тем, кто:

- знает базовый Python;
- хочет разобраться в финансах через данные;
- интересуется алгоритмической торговлей;
- хочет перейти от обычного анализа данных к финансовым временным рядам;
- собирает портфолио проектов в Data Science / Quant / ML

## Как пользоваться

1. Открой основной notebook или roadmap.
2. Иди по темам последовательно.
3. Сначала разбирай смысл темы.
4. Затем закрепляй её кодом.
5. После каждого крупного блока делай небольшой самостоятельный проект.

Не обязательно проходить всё сразу. Roadmap рассчитан на постепенное движение от базовых вещей к более сложным.

Цель — создать понятную точку входа для начинающих, которые хотят не просто копировать код торговых стратегий, а понимать:
